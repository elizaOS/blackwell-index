Methodology

Rental prices for B200, B300, GB200 and GB300, in USD per GPU-hour.

Prices

Public on-demand instance prices are divided by the number of physical GPUs. Region, hardware and included services remain part of each quote. List prices do not guarantee available capacity.

Aggregation

Provider prices use regional medians. Model prices combine provider groups using the weights in each snapshot. The composite is a weighted average of all four model prices.

Availability

A dash means no current qualifying price is available. The composite requires all four model prices.
